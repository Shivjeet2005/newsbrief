# Feedback Log

Filled-in daily feedback goes here, one file per day.

## Workflow
1. After a run, open `feedback-template.txt` in the repo root.
2. Fill in each rating field: `good` / `bad` / or a short note.
3. Save it here as `feedback/YYYY-MM-DD.txt` (e.g. `feedback/2026-09-01.txt`).
4. Commit it.

These accumulate as editorial training data. Later, they get folded
back into the article-ranking prompt so selection improves over time.

`feedback-template.txt` in the repo root is always the LATEST blank
template — it gets overwritten each run, so always save your filled
copy here with the date.
